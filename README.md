### Реализация практических задач Java
1) Исправьте ошибки в следующей программе таким образом, чтобы она отображала числа, кратные 5, от 0 до 100 включительно. Выведите числа по одному в строке.
2) Напишите программу на Java, которая выводит в консоль числовую пирамиду, используя вложенные циклы for.
3) Перепишите приведённый ниже условный оператор if-else в одну строку, сохранив ту же логику.
4) Напишите программу на Java, которая запрашивает у пользователя год (целое число) и определяет, является ли он високосным.
Год считается високосным, если он кратен 4, но не кратен 100, либо кратен 400.
Результат нужно вывести в формате: "[год] год — високосный: [да/нет]".
5) Напишите программу на Java, которая:
сначала выводит приглашение к вводу: Введите оператор: (с пробелом в конце);
считывает с клавиатуры один символ (+ или =) и выводит соответствующее сообщение.
При вводе символа + программа должна вывести "Считан плюс", а при вводе = - "Считано равно". Для решения используйте оператор switch. Программа должна выводить сообщение ровно в указанном формате без дополнительных символов.
Примечание: Программа должна корректно работать только с указанными символами (+ и =), обработка других символов не требуется. Для ввода данных используйте класс Scanner.
6) Напишите программу на Java, которая:
Сначала выводит приглашение к вводу: Введите x: (с пробелом в конце).
Считывает целое число x с клавиатуры.
Вычисляет результаты следующих логических выражений для введённого x:
(true) && (3 > 4)
!(x > 0) && (x > 0)
(x > 0) || (x < 0)
(x != 0) || (x == 0)
(x >= 0) || (x < 0)
(x != 1) == !(x == 1)
Выводит результаты в столбик в формате:
Выражение 1: [результат]
Выражение 2: [результат]
...
Пример работы программы:
Введите x: 1
Выражение 1: false
Выражение 2: false
Выражение 3: true
Выражение 4: true
Выражение 5: true
Выражение 6: true
7) Напишите программу на Java, которая:
Считывает целое число num с клавиатуры.
Вычисляет логическое выражение, которое равно true, если число находится в диапазоне от 1 до 100 не включительно, или если число является отрицательным.
Выводит результат в виде true или false.
Пример работы программы:
Ввод:
50
Вывод:
true
Ввод:
150
Вывод:
false
Ввод:
-7
Вывод:
true
8) Напишите программу на Java, которая:
Считывает целое число variable с клавиатуры.
Если число больше 10 — вычитает из него 10, иначе прибавляет к нему 10.
Перепишите условие с использованием тернарного оператора.
Выведите результат в консоль.
Пример работы программы:
Ввод:
7
Вывод:
17
Ввод:
15
Вывод:
5
9) Напишите программу на Java, которая:
Считывает с клавиатуры строку, обозначающую сигнал светофора: красный, желтый или зеленый.
В зависимости от введенного сигнала выводит:
остановиться — если сигнал красный;
подождать — если сигнал желтый;
ехать — если сигнал зеленый.
Используйте оператор switch.
Программа должна выводить сообщение ровно в указанном формате, без лишних символов.
Пример работы программы:
Ввод:
красный
Вывод:
остановиться
Ввод:
желтый
Вывод:
подождать
Ввод:
зеленый
Вывод:
ехать
10) Напишите программу на Java, которая:
Считывает один символ с клавиатуры.
Выводит строку по правилам дешифрации:
'h' → Hello!
'i', 'm', 'k' → I can decode!
'b' → Bye!
любой другой символ → I don't know these symbols :(
Используйте оператор switch.
Программа должна выводить сообщение ровно в указанном формате, без лишних символов. Ввод производится строчным символом. Ведущие и завершающие пробелы игнорируются.
Пример работы программы:
Ввод:
h
Вывод:
Hello!
Ввод:
i
Вывод:
I can decode!
Ввод:
x
Вывод:
I don't know these symbols :(
